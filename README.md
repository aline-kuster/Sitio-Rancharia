# Sítio Rancharia

Landing page institucional do Sítio Vale Rancharia, com apresentação da estrutura, galeria, acomodações, localização e botão direto para WhatsApp.

## 📌 Visão geral

Este projeto foi criado para apresentar o sítio de forma moderna, elegante e responsiva, com foco em conversão para reservas e contato.

## 🛠️ Tecnologias

- Vite
- TypeScript
- HTML5
- CSS3
- JavaScript

## ✅ Requisitos

- Node.js 18 ou superior
- npm

## 🚀 Como rodar localmente

1. Abra o terminal
2. Entre na pasta do projeto:

```bash
cd lp-rancharia
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o servidor de desenvolvimento:

```bash
npm run dev

```

## 🏗️ Build de produção

Para gerar a versão pronta para deploy:

```bash
npm run build
```

A pasta gerada será:

```text
lp-rancharia/dist
```

Para visualizar a build localmente:

```bash
npm run preview
```
