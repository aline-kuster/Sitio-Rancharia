# Sítio Vale Rancharia

Landing page criada para apresentar o Sítio Vale Rancharia e facilitar o contato de pessoas interessadas em reservar o espaço.

🌐 **Acesse o site:** [lp-rancharia.vercel.app](https://lp-rancharia.vercel.app/)

## Sobre o projeto

O site reúne informações sobre o sítio, fotos dos espaços, opções de hospedagem e orientações para chegar. Os visitantes podem entrar em contato diretamente pelo WhatsApp.

## Tecnologias

- HTML, CSS e TypeScript
- Vite
- React em componentes pontuais
- Tailwind CSS

## Funcionalidades

- Layout responsivo para celular e computador
- Galeria de fotos com navegação
- Menu adaptado para dispositivos móveis
- Botões de contato pelo WhatsApp
- Mapa com localização do sítio

## Executar localmente

É necessário ter Node.js 20.19 ou superior e npm instalados.

```bash
cd lp-rancharia
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
